## 邊啲選擇會改變內容

| 選擇 | 影響 |
|---|---|
| 歲數／出世年份 → 出生組 | 第一章童年物件、第二章課室物件（1960 組有教育電視、體育課）、第三章「後生嘅日子」 |
| 第二章 A／B／C／U | 原有流程不變；C 唔出要正規上學嘅題（教育電視、體育課、學校大樓、天台課室、水上學校），但保留圖書館；U 係唔知道，唔當作冇讀書 |
| 第三章八類經歷「有」 | 加入嗰類物件一回合（每回最多 6 件），可多選 |
| 第三章八類經歷「冇」 | 收起嗰類物件（包括同類嘅分齡物件） |
| 未揀（唔肯定） | 唔加、唔收起 |
| 照顧家人「有」＋ 工廠「冇」＋ 冇揀其他工作類 | 家務回合排第一（煮飯、洗衣、取水、家庭手工）；唔出工廠／返工類物件 |
| 生活地點「香港以外」 | 唔出香港專屬街景（鴨寮街、九鐵、電車）；AI 追問同自傳唔假設喺香港；回憶卡註明相片係香港同類場景 |
| 鄉郊「有」＋ 第二章 A／B | 先會問水上學校 |
| 回憶卡「冇呢段經歷」 | 收起呢件，唔再追問，唔寫入自傳 |

選擇只用嚟揀物件同調整追問，**唔會寫入自傳**；AI 只整理本人親口分享嘅內容。
選題喺本人第一次配對時保存；之後改經歷，已經開始嘅回合唔變，只換未開始嘅回合。

## 回憶卡點樣用新素材嘅問題

| 素材欄位 | 第一、二章 | 第三至五章 |
|---|---|---|
| `entry_question`／原有 `question` | 回憶卡問題 | 回憶卡問題（先確認） |
| `confirmed_question` | 分享後第一條可選追問 | 揀「有，我想分享」之後顯示嘅問題 |
| `follow_up` | 分享後可選追問 | 分享後可選追問（有 AI 時按佢講過嘅內容調整字眼，用確認語氣） |
| `no_experience_response` | — | 揀「冇呢段經歷」之後顯示 |

## 對素材包嘅修改

- 問題、廣東話用字：**冇改**，照原文。
- 相片年份：原 52 項用素材包已核對嘅 `year_from`／`year_to`；「未詳（2024／2025 年報道刊載）」四項當作年份未詳，唔當作拍攝年份。
- 回憶卡顯示：相片年份、來源、檔案編號，另加一句「相片年份唔等於你經歷嘅年份」；相片早過本人出世時改為「只係同類物件參考」。
- 章節 ID：原本預留但未有任何存檔用到嘅 `work`／`retire` 改為 `events`（期間大事件）、`later`（晚年生活）；`childhood`、`learning`、`society` 不變。
